# Forma v1.2.0 — Plan

**Theme:** Not a G-Form clone — forms that travel on WhatsApp and become a small desk.  
**Status:** In progress — slices A–D implemented; E (response status) left as stretch.  
**Last updated:** 2026-08-19

Current product is **v1.1-class MVP**: builder, sections, themes, browser 1-response, onboarding. v1.2.0 is the first **differentiation** release.

---

## 1. Goal

A creator in a paroki / sekolah / komunitas can:

1. Publish a form and **share it on WhatsApp in one tap**
2. Enforce **one person, one response** using HP or email (not a Google account)
3. Start from an **acara template** and see a **daftar hadir**, not only a spreadsheet dump
4. Give the respondent a **bukti kirim** they can keep

If we remove the Forma name, it should still not feel like Google Forms.

---

## 2. In scope

### A. WhatsApp share pack
- From the form action bar: **Bagikan ke WhatsApp**
- Opens `wa.me` with: form title, one-line description, short public URL
- Optional: download a simple **share card image** (title + Forma + URL) for status/grup
- Copy caption as text (for users who paste manually)

### B. Unique respondent (HP / email)
- Settings: **Batasi 1 respons** gains a mode:
  - Browser only (current cookie) — keep as default
  - **Nomor HP unik** or **Email unik** (pick an existing question, or auto-add one)
- Server rejects a second submit with the same normalized HP/email on that form
- Public fill: clear error on that field (“Nomor ini sudah terdaftar”)
- Owner can still see who collided (no silent drop)

### C. Acara templates + daftar hadir
- Dashboard: **Mulai dari template** (not only blank)
- v1.2.0 templates (Bahasa Indonesia):
  1. Pendaftaran acara / RSVP
  2. Pendataan singkat (nama, HP, wilayah)
  3. Umpan balik kegiatan
- Each template: title, sections, questions, confirmation, suggested 1-response on HP
- Responses tab: **Daftar hadir** view — table of name + HP + time (mapped from template fields; fallback first short-text + email/phone-like questions)
- Print-friendly daftar hadir (browser print CSS), plus existing CSV

### D. Bukti kirim (submit receipt)
- After submit: confirmation **and** a receipt block (form title, time, short response id)
- **Simpan / cetak** (print) and **Salin ringkasan**
- Optional: show the unique HP/email they used

### E. Stretch (only if A–D are done)
- Response status: `baru` | `diproses` | `selesai` (owner-only, list + detail)
- Filter daftar hadir by status
- Skip full assignment/petugas (that is v1.3)

---

## 3. Out of scope (v1.2.0)

- WhatsApp Business API / reply “HADIR” in chat
- OTP SMS/WA (unique HP is enough for v1.2)
- NIK validation against Dukcapil
- Save-and-continue across devices (v1.3)
- Collaborators, branching, quiz, Sheets, payments
- Custom CSS themes, AI generate
- Full parish directory / wilayah picker (can be a dropdown question in the template, not a new entity)

---

## 5. Product rules

- UI stays **Bahasa Indonesia**; dates `id-ID`; phone stored digits-only (`08…` / `62…` normalized)
- Layers unchanged: UI → actions/API → domain → db
- Validate with Zod on the server; unique HP/email is a **domain rule**, not only a UI check
- Index `responses` for unique lookup: `formId + normalizedKey` (sparse; only when unique mode is on)
- WA share uses the existing short link (`/f/{shortCode}`)
- Templates are data in `src/lib/form-templates.ts` (no CMS)
- DESIGN.md: still teal/paper; share card uses Forma tokens, not G-Form purple

---

## 6. Data sketch

```
forms
  limitOneResponse          # existing browser cookie
  uniqueBy?: null | "phone" | "email"
  uniqueQuestionId?: string # which question supplies the key

responses
  meta.respondentKey        # existing browser key
  meta.uniqueKey?: string   # normalized HP or email
```

Template create copies questions/sections like duplicate, then owner edits.

---

## 7. Success for v1.2.0

- Creator shares a live form to WhatsApp without leaving Forma
- Duplicate HP/email cannot register twice on a form with unique mode
- A non-technical user can launch “Pendaftaran acara” in &lt; 3 minutes
- Respondent can print/save a receipt after submit
- Still no Google account required for respondents
